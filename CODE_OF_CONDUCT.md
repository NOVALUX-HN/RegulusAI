# Code of Conduct (NOV-86 Paso 66)

Short, enforceable version of the Contributor Covenant adapted to this
project. Be kind, be precise, assume good faith; no harassment, no
hate speech, no sexualized content, no doxxing, no sustained
disruption. Technical disagreement is welcome — attack the argument,
never the person.

## Scope

Issues, pull requests, reviews, discussions and any space where the
project is maintained. Maintainers may remove contributions or
participation that violates this code.

## Enforcement

Report privately through the channel in `SECURITY.md` (GitHub Private
Security Advisories — do not open a public issue for conduct reports
either). There is no committee today: the maintainer triages, warns or
bans, and records the decision privately. Appeals go to the same
channel within 30 days.
